# 보도자료 · 뉴스 · 블로그 · 검색 · AI 발견성 운영 계획

- 기준일: 2026-07-26
- 적용 도메인: DreamAI Lab 생태계 공개 도메인 전체

## 원칙

소유 도메인 사이의 링크는 엔터티 관계와 탐색성을 높이지만, 독립 언론의 검증과 같지 않다. 보도자료는 사실·날짜·담당 조직·근거 URL을 갖춘 원문으로 배포하고, 매체가 독립적으로 편집·게재한 기사만 외부 보도 실적으로 분류한다.

검색 순위나 모든 AI 모델의 학습을 보장하는 표현은 사용하지 않는다. 검색 노출, 검색 기반 AI 답변의 인용 가능성, 학습 데이터 편입은 서로 다른 결과다.

## 콘텐츠 허브와 배포 순서

1. DreamAI Lab 뉴스에 공통 기술·연구 사실의 원문을 게시한다.
2. 서비스 도메인에는 해당 산업 적용, 사용 방법, 책임 경계와 실제 운영 사실만 게시한다.
3. 네이버 블로그·브런치·미디엄·LinkedIn 등 외부 채널에는 요약본을 게시하고 정본 canonical URL로 연결한다.
4. 보도자료 배포 시 제목·날짜·법인명·연락처·근거 링크를 고정하고 과장된 성과나 보장 표현을 제거한다.
5. 실제 게재 URL은 발행 매체, 발행일, 언어, 대상 국가, 원문 정본과 함께 배포 장부에 기록한다.

## 검색엔진 운영

각 도메인을 별도 속성으로 등록하고 소유권·색인 상태를 따로 관리한다.

| 채널 | 필수 운영 |
|---|---|
| Google Search Console | 도메인 속성, 사이트맵 제출, 주요 canonical URL 색인 검사 |
| Naver Search Advisor | 사이트 소유 확인, robots 확인, 사이트맵·RSS 제출, 주요 페이지 수집 요청 |
| Bing Webmaster Tools | 사이트맵 제출, IndexNow 키와 전송 로그 관리 |
| 기타 글로벌 검색 | 표준 robots, canonical, hreflang, sitemap을 기본으로 운영 |

IndexNow는 추가·수정·삭제된 공개 URL만 전송한다. 동일 URL의 과도한 반복 제출을 피하고 키 파일과 전송 결과를 운영 기록에 남긴다.

## 언어 전략

- 연구자와 공통 기술 정본은 한국어·영어를 우선 제공한다.
- 해외 사용자가 실제로 존재하는 서비스는 번역 품질과 현지 책임 문구를 검수한 뒤 일본어·베트남어 등으로 확장한다.
- 언어별 페이지는 직역된 키워드 모음이 아니라 해당 국가 사용자의 질문과 제도·용어를 답한다.
- 번역 페이지는 상호 hreflang과 x-default를 유지한다.

## 보도자료 초안 필수 필드

- 사실 중심 제목
- 발표 주체의 정확한 법인·브랜드명
- 발표일과 적용 서비스
- 무엇이 새로 공개·변경되었는지
- 검증 가능한 정본 URL
- 개인정보·의료·투자 책임 경계
- 언론 문의 연락처

## 측정

월 1회 도메인별로 다음을 기록한다.

- 색인된 canonical URL 수와 제외 사유
- 브랜드·인물·기술명 검색 노출 변화
- 검색 질의별 클릭·노출·CTR
- 외부 매체·기관의 실제 인용과 링크
- AI 검색 답변에서 정본 URL이 근거로 사용되는지 여부
- 잘못된 엔터티 병합, 오래된 설명, 개인정보 재노출 여부

성과 수치는 검색 콘솔이나 실제 로그의 기간·출처와 함께 적고, 소유 채널 게시물 수와 독립 외부 보도를 분리한다.
