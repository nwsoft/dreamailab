# Dream AI Lab Corporate Web Design System

> 기준일: 2026-08-17
> 적용 대상: dreamailab.com의 회사·기술·서비스·연구·뉴스 공개 페이지

## 1. 사이트의 역할

Dream AI Lab 웹사이트는 개별 서비스를 직접 운영하는 앱이 아니라 회사의 기술, 사업, 연구, 성과와 연락 경로를 설명하는 기업 정보 사이트다.

모든 페이지는 다음 질문에 빠르게 답해야 한다.

1. 드림에이아이랩이 무엇을 하는 회사인가
2. 이 페이지의 기술·서비스·연구가 회사 전체 구조에서 어디에 속하는가
3. 현재 단계와 확인 가능한 사실은 무엇인가
4. 더 자세한 자료와 문의 경로는 어디인가

## 2. 공통 시각 언어

### 색상

- Primary Blue: `#0F5EB8` — 기업·기술·링크·주요 행동
- Secondary Teal: `#159F8C` — 확장·연결·보조 강조
- Ink: `#0F172A` — 제목과 본문 핵심
- Muted: `#475569` — 보조 설명
- Border: `#E2E8F0` — 카드와 섹션 구분
- Surface: `#FFFFFF`
- Muted Surface: `#F8FAFC`

도메인별 보라·주황·청록은 아이콘, 작은 배지, 데이터 시각화의 보조색으로만 사용한다. 페이지 전체 히어로 또는 연속된 섹션의 주 색상으로 사용하지 않는다.

### 타이포그래피

- 페이지 H1: 모바일 30px, 데스크톱 최대 48px
- 섹션 H2: 24–36px
- 본문: 16–18px, 충분한 행간
- 영문 대문자 라벨은 짧게 사용하고, 한국어 정보 위계를 우선한다.

### 공간과 폭

- 공통 최대 폭: 1280px
- 읽기 본문 최대 폭: 768–896px
- 히어로 상하 여백: 64–80px
- 섹션 상하 여백: 56–80px
- 카드 모서리: 16px 중심, 큰 CTA만 24px 허용

## 3. 페이지 구조

### 기업형 히어로

모든 주요 허브와 신규 연구·프로젝트 페이지는 동일한 Blue → Teal 히어로를 사용한다.

구성 순서는 다음과 같다.

1. 회사 또는 페이지 분류 라벨
2. 한 개의 H1
3. 2–3문장 설명
4. 필요한 경우 분류·단계 배지
5. 필요한 경우 짧은 현재 단계 설명
6. 최대 두 개의 행동 버튼

대시보드, 채팅창, 코드 편집기처럼 보이는 제품 UI 모형은 기업형 히어로에 배치하지 않는다. 이해를 돕는 예시는 본문 정보 카드로 이동한다.

### 본문 섹션

- 흰색과 Muted Surface를 교대로 사용한다.
- 한 페이지의 짙은 배경 섹션은 필요할 때 한 번만 사용한다.
- 동일 페이지에서 보라·주황·청록·남색 전체 배경을 연속 사용하지 않는다.
- 카드 하나마다 서로 다른 색을 부여하지 않는다. 색은 상태 또는 의미가 있을 때만 사용한다.

### 상태 표현

- `Commercial`, `Pilot`, `Development`, `Research`, `Future Vision`처럼 짧은 공통 단계명을 사용한다.
- 상태 설명은 사실 위주로 한 문단 이내로 작성한다.
- 외부 기사 원문에 없던 편집자 판단이나 방어적 고지를 삽입하지 않는다.
- 제품 홍보, 연구 비전, 외부 기사 발췌를 서로 다른 정보 유형으로 명확히 구분한다.

## 4. 콘텐츠 원칙

- 시장에서 통용되는 범주명을 먼저 사용한다. 예: 바이브코딩, AI 앱 빌더.
- DAL의 차별화는 별도 문장으로 설명한다. 범주 자체를 새로 만들었다고 주장하지 않는다.
- 특정 경쟁제품 하나를 전체 시장의 대명사로 사용하지 않는다.
- 공개 수치, 시장점유율, 출시 상태는 출처와 기준일이 있을 때만 단정한다.
- 회사 소개 페이지에서 기능 목록보다 기술 철학, 산업 구조, 실증과 현재 단계를 우선한다.

## 5. 접근성·반응형 기준

- 키보드만으로 모든 링크·버튼·상세 요소에 접근 가능해야 한다.
- 포커스 표시를 제거하지 않는다.
- 본문과 배경은 WCAG AA 수준 대비를 목표로 한다.
- 모바일 320px 이상에서 가로 스크롤이 없어야 한다.
- 긴 단계·목차 배지는 가로 스크롤 또는 자연스러운 줄바꿈을 제공한다.
- 의미 있는 이미지는 대체텍스트를, 장식 이미지는 빈 대체텍스트를 사용한다.
- 자동 다크모드로 회사 색상과 대비가 임의로 뒤집히지 않도록 기본 색상 체계를 고정한다.

## 6. 적용 우선순위

1. 공통 헤더·푸터·기업형 히어로
2. 서비스·연구 허브
3. Robot Vision·Pet AI·DAL Vibe Architect
4. 뉴스·회사·기술 상세 페이지
5. 모바일·키보드·대비·초기 HTML 및 SEO 확인

새 페이지는 이 문서와 `CompanyPageHero`, `company-*` 공통 CSS를 기준으로 제작한다.
